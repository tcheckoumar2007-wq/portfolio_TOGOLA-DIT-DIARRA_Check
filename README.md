# Portfolio GEII — Check Togola Diarra

Site statique en HTML, CSS et JavaScript, responsive et sans compilation.

## Ouvrir

Ouvre `index.html` dans un navigateur. Pour travailler dans VS Code, l'extension Live Server est pratique.

## Pages

- `index.html` : accueil
- `projets.html` : galerie des projets
- `projet-robot-slalomeur.html`, `projet-mini-sumo.html`, `projet-mugochaud.html`, `projet-poste-chargement.html`, `projet-stage.html` : fiches détaillées
- `competences.html` : compétences Concevoir, Vérifier, Maintenir et Intégrer
- `parcours.html` : formation, expérience et outils
- `cv.html` : présentation du profil et téléchargement du CV PDF
- `contact.html` : coordonnées

## Mise en ligne

Le site peut être hébergé sur GitHub Pages, Netlify ou tout hébergement web statique. Aucun outil de compilation n'est nécessaire.

## Navigation

- Le CV PDF se télécharge depuis la page CV.
- La galerie des projets comprend une recherche textuelle et des filtres par domaine.
- Le lien « Aller au contenu » est disponible au clavier ; le bouton de retour en haut apparaît après défilement.
