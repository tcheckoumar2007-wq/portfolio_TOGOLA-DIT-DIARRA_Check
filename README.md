# Portfolio GEII — Check Togola Diarra

Site statique en HTML, CSS et JavaScript, responsive, sans compilation.

## Ouvrir
Ouvre `index.html` dans un navigateur. Pour travailler dans VS Code, l'extension Live Server est pratique.

## Pages
- `index.html` : accueil
- `projets.html` : galerie des projets
- `projet-mini-sumo.html`, `projet-mugochaud.html`, `projet-stage.html` : fiches détaillées
- `competences.html` : les compétences Concevoir, Vérifier, Maintenir, Intégrer
- `parcours.html` : formation, stage et outils
- `contact.html` : coordonnées

## À personnaliser avant publication
- Les illustrations SVG dans `assets/images/` sont des visuels conceptuels, pas des photos de tes réalisations. Remplace-les par tes propres photos et captures.
- Complète les fiches avec les détails exacts : matériel, logiciels, rôle individuel, résultats mesurés, difficultés et bilan personnel.
- Vérifie les intitulés exacts de formation et diplôme.
- Ajoute ton URL LinkedIn réelle.
- N'expose aucun document confidentiel de stage ; anonymise les captures et demande les autorisations nécessaires.

## Mise en ligne
Le site peut être hébergé sur GitHub Pages, Netlify ou un hébergement web statique.

- projet-poste-chargement.html : SAE de BUT 3 — poste automatisé de chargement/déchargement

- `cv.html` : présentation web du profil et téléchargement du CV PDF

## Raccourcis et navigation
- Le CV PDF se télécharge depuis l’accueil, le menu principal ou la page CV.
- La galerie des projets comprend une recherche textuelle et des filtres par domaine.
- Le lien « Aller au contenu » apparaît à la navigation clavier ; le bouton retour en haut apparaît après défilement.
